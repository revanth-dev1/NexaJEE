# Nexa JEE — JEE Main 2027 Preparation Desk 🎯

> **Designed and Developed with care by Revanth** for **Nishu Kumari**

A comprehensive, interactive web dashboard engineered for JEE Main 2027 preparation. Includes deep 10-year PYQ analysis, complete chapter syllabus breakdown, formula revision sheets, mock test simulation arena, cheat sheets, and an AI doubt assistant.

---

## 🚀 Live Demo
🌐 **[Launch Nexa JEE](https://revanth-dev1.github.io/NexaJEE/)**

---

## ✨ Key Features

### 1. 📊 10-Year PYQ Analysis & Question Type Breakdown
- **1,500+ questions analyzed** across Physics, Chemistry, and Mathematics from 2015–2024.
- **Interactive Chapter Rows**: Click any chapter to inspect the exact question types asked.
- **Recurrence Badges**: Frequency tags (*"Every year"*, *"9/10 years"*, etc.) with visual frequency bars.
- **Year-wise Breakdown Table & Hot Topic Predictions** for JEE Main January 2027.

### 2. 📚 Comprehensive Chapter Syllabus & Formulas
- Detailed syllabus mapping for all high-weightage chapters.
- **Clickable Syllabus Tags**: Click any topic to immediately navigate to its key formulas.
- Direct quick-actions to practice tests, formulas, and PYQs.

### 3. ⏱️ Mock Test Arena
- Full 180-minute JEE Main exam simulator (75 questions: Physics + Chemistry + Maths).
- Subject-specific practice modes.
- Instant score reporting, accuracy tracking, and personalized weakness analysis.

### 4. 📝 Formula Desk & Quick Revision Sheets
- Key formulas categorized by chapter.
- Search and filter formulas across Physics, Chemistry, and Mathematics.

### 5. 🤖 AI Doubt Assistant & Daily Study Tracker
- Instant doubt clearing for high-frequency JEE concepts.
- Daily streak tracker, completion milestones, and motivational study tips.

## 🛠️ Tech Stack

- **HTML5 & CSS3**: Vanilla CSS with modern glassmorphism, responsive grid & flexbox design, dark theme.
- **JavaScript (ES6+)**: Zero external framework dependencies; blazing fast load times on any device.
- **Hosting**: GitHub Pages.

## 📦 Local Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/revanth-dev1/NexaJEE.git
   ```
2. Navigate to the project directory:
   ```bash
   cd NexaJEE
   ```
3. Open `index.html` in your favorite browser, or start a local server:
   ```bash
   npx serve .
   ```
